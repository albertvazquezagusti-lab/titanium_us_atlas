# Hispanic-Majority County Atlas

Interactive map of the 20 most populous US counties where Hispanic residents are a majority, with payer mix and orthopedic hospital and surgery-center supply.

The site is a single static page (`index.html`) with the data built in. It loads d3, topojson and map outlines from public CDNs.

Sources: US Census Bureau (QuickFacts, ACS) and CMS public files (Medicare enrollment, Medicare Advantage enrollment by county, Hospital General Information, Provider of Services, Medicare Inpatient Hospitals by Provider and Service), plus state Medicaid agency plan lists. Data as of November 2026.
